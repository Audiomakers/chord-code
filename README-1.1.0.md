# CHORD CODE PRO 1.1.0

Build Windows x64 atualizada em 28/09/2026.

## Instalação

- `Chord Code Pro 1.1.0 Setup.exe`: instala o VST3 e já sugere `C:\Program Files\Common Files\VST3`.
- `Chord Code Pro.vst3`: arquivo solto para instalação manual na pasta VST3 comum.

## Ajustes desta build

- moldura antiga que atravessava a interface removida;
- lock redesenhado, com estado ativo laranja claro e sem sobreposição;
- engrenagem branca e sem hover;
- `PADRÃO` aparece primeiro em Estilo e Vibe;
- comprimento sincronizado com a progressão: `1/2 = 2 acordes`, `1 = 4 acordes`, `2 = 8 acordes`;
- `CONTINUAR` seleciona automaticamente 2 compassos e abre os acordes 5–8;
- retorno à primeira página seleciona 1 compasso e mantém quatro acordes;
- cards 3 e 4 ficam cinza/inativos em 1/2 compasso;
- `BOUNCE` substituído por `ARPEJO`;
- Humanize, Strum e Arpejo alteram a prévia e o MIDI exportado;
- controle `VELOCIDADE` substituído por `VOLUME`, iniciando em 100%;
- alinhamento do cabeçalho e distância entre CHORD CODE e PRO refinados.
- novo ícone oficial aplicado ao plugin e ao instalador;
- instalador minimalista com suporte a DPI moderno e somente VST3;
- target e distribuição Standalone removidos.

Após instalar, no FL Studio use `Options > Manage plugins > Find installed plugins` e habilite o rescan dos plugins já verificados.
