# Chord Code Pro 2.1.0

## Instalação no Windows

- **Instalador:** execute `Chord Code Pro 2.0 Setup.exe`, escolha VST3, Standalone ou ambos e confirme as pastas. A pasta VST3 padrão é `C:\Program Files\Common Files\VST3`.
- **Manual:** copie `Chord Code Pro.vst3` para `C:\Program Files\Common Files\VST3\` e faça uma nova busca de plugins no FL Studio.
- **Standalone:** `Chord Code Pro Standalone.exe` abre sem uma DAW.

## Principais recursos

- Progressões de 4 ou 8 acordes, locks individuais e histórico das últimas 10 gerações.
- Variações sequenciais e memória antirrepetição de progressões e acordes.
- Estilos, incluindo Jazz e Padrão; vibes, incluindo Padrão; tensão e complexidade.
- Voicings padrão, fechado, aberto e invertido com condução de vozes.
- Ritmos MIDI reto, humanize, strum e bounce, adaptados ao estilo.
- Comprimentos de 1/2, 1, 1 e 1/2 ou 2 compassos por acorde.
- Sincronização com o BPM do projeto e BPM manual de segurança.
- Exportação de acordes e bassline em MIDI formato 0 (uma faixa).
- Piano aprimorado, soft keys, synth saw, órgão, pad, violino, flauta e piano elétrico.
- Aleatório preserva o timbre selecionado.
- Interface fixa de 1536 × 940 fiel ao frame oficial do Figma, com timer visual encerrado antes do teardown do editor.
- Migração automática do estado salvo pela versão 1.x.

## Atualizações

Abra **Configurações > Verificar atualizações** no plugin. A verificação abre a página oficial no navegador e não executa downloads em segundo plano.
