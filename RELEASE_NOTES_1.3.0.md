# Chord Code 1.3.0

## Novidades
- **Janela redimensionável**: arraste o canto inferior direito para aumentar ou diminuir (de 60% a 200%, mantendo a proporção).
- **Tamanho padrão** em Configurações > JANELA: 75%, 90%, 100%, 125% ou 150%. Clicar muda a janela na hora e vira o tamanho de todas as janelas novas do Chord Code no computador (salvo junto da licença). Arrastar o canto muda só a janela aberta.
- **ARRASTAR WAV**: arraste a progressão como áudio direto para a DAW, com o timbre, ritmo, duração e BPM escolhidos. WAV 24-bit 44,1 kHz estéreo, normalizado em -1 dBFS e em loop perfeito (o final do último acorde volta no começo).
- **SALVAR** agora abre um menu: Salvar MIDI ou Salvar WAV.
